# Internal audits and reports

These documents are internal engineering-audit artifacts from the project's
hardening phase (2026-11-14 .. 2026-11-19). They are retained **for transparency,
not as external quality claims**.

- `BUG_REGISTRY.md` — tracked bug list with status.
- `ENGINEERING_CHECKUP_REPORT.md` — engine audits and DDP validation.
- `GITHUB_MIGRATION_REPORT.md`, `GITHUB_MIGRATION_INVENTORY.md` — inventory when the project was migrated to `github.com/Neuratal/NTransformer`.
- `PERFORMANCE_AUDIT_REPORT.md` — dev benchmarks and methodology.
- `SECURITY_AUDIT_REPORT.md` — threat-model notes for serialization.
- `TEST_RESULTS.md` — captured test output.

They are reference material for contributors; none of them constitute a
correctness or performance qualification beyond the tests in `tests/`,
see `docs/limitations.md`.
