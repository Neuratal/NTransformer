## Suggested page outline

- Hero: **NTransformer — the open-source PyTorch Transformer from Neuratal**
- Key features: decoder-only GQA, RoPE, SwiGLU, RMSNorm, long context (16K/32K),
  KV cache, factorized tied embeddings, NTokenizer integration.
- Install snippet: `pip install neuratal-transformer`
- Links: GitHub (https://github.com/Neuratal/NTransformer), Hugging Face (https://huggingface.co/Neuratal),
  NTokenizer (https://huggingface.co/Neuratal/ntokenizer).
- License: Apache-2.0.
